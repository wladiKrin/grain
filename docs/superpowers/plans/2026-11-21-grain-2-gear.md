# Grain 2 — Gear library: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grain knows the photographer's gear: a bundled community library of bodies and lenses (JSON in the repo, validated in CI), user profiles and favorites in a Drift database, dials that offer only the values the selected body and lens can set (Bulb included, zooms with varying maximum aperture, a focal dial for zooms), a lens chip that cycles favorite lenses in one tap, library/picker/editor screens, sharing of bodies, lenses and kits as a JSON file or a QR code with in-app QR scanning, and the ultra-wide camera when the lens is wider than the phone's main camera.

**Architecture:** A pure-Dart gear layer (`lib/gear/`) parses and validates the library JSON format, encodes it (pretty for files, compact for QR) and turns a body + lens + focal length into `GearScales` that feed the existing solver and dials unchanged. `GearController` (plain `ChangeNotifier`) joins the read-only bundled `GearLibrary` with a `GearRepository` (Drift on device, in-memory in tests) holding user profiles, favorites and the current selection; `GrainApp` pushes its `GearSetup` into `MeterController.setGear`. The Kotlin Camera2 bridge gains an ultra-wide switch and a QR scan mode that decodes the Y plane with ZXing core — no Google Play Services anywhere.

**Tech Stack:** Flutter 3.50.1 (Dart 3.14), Kotlin + Camera2, Drift 2.35 (`drift_flutter`, codegen via `build_runner`, generated files committed), `share_plus`, `file_selector`, `qr_flutter`, `path_provider`, ZXing core (Java, Apache-2.0); dev: `json_schema` for the library check.

**Spec:** `docs/superpowers/specs/2026-11-21-lightmeter-design.md` (binding; §5.1 header/lens chip/zoom dial, §5.2 snapping and ultra-wide, §5.3 gear library, §3 constraints, §4 storage). Plan 1: `docs/superpowers/plans/2026-11-21-grain-1-meter.md`; its rulings and deferred minors: `docs/superpowers/plans/2026-11-21-grain-1-meter-followups.md`.

**Later plans (not this one):** 3 Rolls & logging (adds rolls/frames tables to the same `GrainDatabase`, roll status in the header, body fixed per roll, Android backup) · 4 Histogram & polish (histogram, shake warning, click sound, F-Droid release incl. building SQLite from source).

## Review Focus

1. **Foreign or future input** — a JSON file from a newer Grain (`"schema": 2`), a random text/JSON file, or someone else's QR code (a URL) → a clear "Not a Grain profile" / "made by a newer version of Grain" message, nothing imported, scanning continues, no crash. Tests in Task 2 and Task 11.
2. **Selected gear disappears** — the user deletes the selected profile, or an app update removes/renames a bundled id stored in the selection → app starts, falls back to "No camera" (or the lens rule), never throws. Tests in Task 7 and Task 10.
3. **Switching gear while dial values are off the new scale** (1/4000 set, switch to the A-1 whose fastest is 1/1000; f/1.4 set, switch to an f/1.8 lens; ISO 12800 set, body max 3200) → each dial lands on the nearest value the new gear has, results re-solve, no index out of range. Test in Task 8.
4. **Zooming a varying-aperture zoom while wide open** (35–70 f/3.5–4.5 at f/3.5, zoom to 70 mm) → aperture becomes f/4.5, the new widest; zooming back keeps f/4.5 (the user's value, now valid). Test in Task 8.
5. **Importing the same thing twice / importing what is already bundled** → no duplicate list entries; an identical profile is reused and starred; only differing content with a taken id creates a suffixed copy. Test in Task 7.

## Rulings made while planning (do not re-open)

- **Bulb:** dials offer timed speeds only. In aperture priority, when the solved shutter is under-range and the body has `B` or `T` (free mode has Bulb), the result row shows **"B"** with the exact time (e.g. `45"`, `2m 30s`) in place of "▼ under".
- **Off-grid limits:** an off-grid limit (lens f/1.7 on a third-stop grid) is its own end value; the adjacent inside grid value is dropped when it lies **less than ¼ stop** from the limit (so `1.7, 2, 2.2…`, not `1.7, 1.8, 2…`; but f/1.8 full-stop keeps `1.8, 2, 2.8`).
- **Zoom maximum aperture** is interpolated linearly in stops over log focal length between the lens's breakpoints, then rounded **up** (to the smaller opening) to the nearest value of the lens's step grid or a breakpoint value (0.05-stop tolerance).
- **Kit** = a body plus its favorite lenses for the mount (plus the current lens if it fits); no lens checklist in v1.
- **Imported profiles are starred**; an import identical (ignoring id) to an existing profile reuses it.
- **Lens chip:** tap cycles favorite lenses for the mount (one gesture, spec anti-goal); with no favorites a tap opens the lens picker; a "more…" link beside it always opens the picker. Zooms and no-lens setups get the focal chip next to it (existing bottom-sheet dial). "No camera" shows only the focal chip.
- **Body without a lens selected** uses free-mode apertures (thirds f/1–f/64) and the free focal dial. Choosing a body auto-selects: the current lens if it fits; else its first favorite lens for the mount; else the mount's only lens (fixed-lens cameras); else none.
- **Ultra-wide** is used when `equivalentFocal(focal, format) < mainEqFocal`; native prefers `CONTROL_ZOOM_RATIO` < 1 on the main logical camera (API ≥ 30), else a separate back camera with eq. focal < 0.8 × main, else none.
- **QR scanning** opens the camera in a separate scan mode (larger YUV reader, no stats); `MeterController.lendCamera` keeps the meter from reopening the camera meanwhile.
- **SQLite on Android** comes from `sqlite3`'s build hook (prebuilt, sha256-checked download). F-Droid forbids prebuilt binaries: plan 4 switches to `hooks: user_defines: sqlite3: source: source` with a vendored amalgamation.

### Task 1: Scales for gear limits and body shutter lists

**Files:**
- Modify: `lib/exposure/scales.dart`, `lib/exposure/solver.dart` (doc comment of `_snap`; null for non-finite/≤ 0 exact targets)
- Test: `test/exposure/scales_test.dart`, `test/exposure/solver_test.dart`

**Interfaces:**
- Consumes: existing `ScaleValue`, `StepSize`, `apertureScale`, `shutterScale`, `isoScale`, `nearestIndex`.
- Produces:
  - `List<ScaleValue> bodyShutterScale(List<String> marks)` — marks are library shutter strings (`"1/1000"`, `"1"`, `"30"`, `"0.7"`, `"B"`, `"T"`); `B`/`T` are skipped; result is fastest → slowest, duplicates removed. A mark whose display label (`"1/N"`, or seconds as `N"`) is in the thirds table takes that entry's exact value and full-stop flag; else in the halves table likewise; else its nominal value, `isFullStop = false`. Throws `ArgumentError` for an unparsable mark or when no timed mark remains.
  - `String formatSeconds(double s)` — `< 1` → `1/N` (N = round(1/s)); `< 10` → one decimal with trailing `.0` dropped plus `"`; `< 60` → whole seconds `"`; `< 3600` → `'${m}m ${ss}s'` (ss two digits); else `'${h}h ${mm}m'` (minutes rounded).
  - `nearestIndex` throws `ArgumentError` for an empty scale or a value that is ≤ 0 / non-finite.
  - `solveShutter` / `solveAperture` return `null` when the exact target is non-finite or ≤ 0.
  - `_build` rules: an off-grid limit is an extra end value (existing); **new:** the adjacent inside grid value is dropped when `|log2 stops|` between it and the limit is `< 0.25` (aperture stops = `2·log2(N ratio)`). Limits within 0.05 stop of a grid value keep the grid value (ruling; documented in the `_limitTolerance` comment). `_shutterLimit(v)` labels `1/N` only when `1/v` is within 1 % of an integer, else seconds via `_plain` + `"`.

  - `sealed class GearDoc {}`; `sealed class GearProfile extends GearDoc { String get id; String get make; String get mount; ProfileKind get kind; String get displayName; }`
  - `final class Body extends GearProfile { const Body({required id, required make, required model, required mount, required FilmFormat format, required int frames, required List<String> shutter, int isoMin = 6, int isoMax = 12800}); bool get hasBulb /* contains B or T */; displayName => '$make $model'; Body copyWith({...}); }`
  - `class ApertureAt { const ApertureAt(this.focal, this.aperture); final double focal, aperture; }`
  - `final class Lens extends GearProfile { const Lens({required id, required make, required name, required mount, required double focalMin, required double focalMax, required List<ApertureAt> maxAperture, required double minAperture, required StepSize apertureStep}); bool get isZoom; displayName => name; String get shortName /* name with RegExp(r'(\d)mm f/') → r'$1/' : "FD 50mm f/1.8" → "FD 50/1.8" */; Lens copyWith({...}); }` — a prime has one `ApertureAt(focal, N)`.
  - `final class Kit extends GearDoc { const Kit(this.body, this.lenses); final Body body; final List<Lens> lenses; }`
  - `Body`, `Lens`, `ApertureAt` have value `==`/`hashCode` over all fields (lists element-wise).
- Produces (`lib/gear/codec.dart`):
  - `class GearFormatException implements Exception { GearFormatException(this.errors); final List<String> errors; /* '<path>: <message>' */ }`
  - `GearDoc parseGear(Object? json)` and `GearDoc parseGearString(String text)` — throw `GearFormatException` (never `TypeError`/`FormatException`).
  - `Map<String, Object?> gearToJson(GearDoc doc, {bool compact = false})`, `String encodePretty(GearDoc doc)` (2-space indent + trailing `\n`), `String encodeCompact(GearDoc doc)` (minified, `compact: true`).
  - `enum QrEc { m, l }`; `class QrPayload { const QrPayload(this.data, this.ec); final String data; final QrEc ec; }`; `QrEc? qrLevelForBytes(int n)` (≤ 2331 → m, ≤ 2953 → l, else null); `QrPayload? qrPayloadFor(GearDoc doc)`.

File format (schema 1; key order of `gearToJson` is exactly as listed):
```
body: {"schema":1,"type":"body","id","make","model","mount","format","frames"?,"shutter":[...],"iso"?:[min,max]}
lens: {"schema":1,"type":"lens","id","make","name","mount","focal": N | [min,max],
       "maxAperture": N | [[focal,N],...], "minAperture": N, "apertureStep": "full"|"half"|"third"}
kit:  {"schema":1,"type":"kit","body":{body without "schema"},"lenses":[lens without "schema", ...]}
```
Validation rules (each violation → one error string; collect all):
- top level: `schema` must be the integer 1 (an integer > 1 → `'schema: made by a newer version of Grain (schema N)'`); `type` ∈ body/lens/kit; unknown keys are errors; nested kit objects must not carry `schema`.
- `id`: `^[a-z0-9][a-z0-9.-]{0,63}$`; `mount` same pattern; `make`, `model`, `name`: non-empty, ≤ 60 chars after trim.
- body: `format` ∈ `FilmFormat` ids; `frames` int 1–200, default `format.defaultFrames`; `shutter` non-empty, unique, each `^(1/[1-9][0-9]*|[0-9]+(\.[0-9]+)?|B|T)$`, at least one timed mark (`'shutter: needs at least one timed speed'`); `iso` `[min, max]` ints with `6 ≤ min < max ≤ 12800`, default `[6, 12800]`.
- lens: `focal` > 0, or `[min, max]` with `min < max`; prime → `maxAperture` must be a number; zoom → number (constant) or ≥ 2 pairs, focals strictly ascending, first = focal min, last = focal max; every aperture in `[0.7, 64]`; `minAperture` > every max aperture and ≤ 64.
- kit: `body` is a body; `lenses` 1–20 lenses, each `mount == body.mount` (`'lenses[2].mount: does not fit canon-fd'`).
- compact output omits `frames` when equal to the format default and `iso` when `[6, 12800]`; full output always writes them. Numbers that are whole are written as ints (`22`, not `22.0`).

- Produces:

  - `class GearScales { final List<ScaleValue> apertures, shutters, isos, focals; final bool hasBulb; final FilmFormat format; }`
  - `GearScales scalesFor(GearSetup s)`: shutters — free `shutterScale(step: third)`, else `bodyShutterScale(body.shutter)`; apertures — no lens `apertureScale(step: third)`, else `apertureScale(step: lens.apertureStep, min: effectiveMaxAperture(lens, s.focal), max: lens.minAperture)`; isos — free `isoScale()`, else `isoScale(min: body.isoMin, max: body.isoMax)`; focals — no lens: `focalStops` as `ScaleValue('$f', f, false)`; prime: `[focalMin]`; zoom: `focalValuesFor(lens)`; `hasBulb` — free true, else `body.hasBulb`; `format` — `body?.format ?? FilmFormat.f135`.
  - `List<ScaleValue> focalValuesFor(Lens zoom)` — `[focalMin] + focalStops strictly inside + [focalMax]`, labels whole numbers.
  - `double effectiveMaxAperture(Lens lens, double focal)` — algorithm:
    ```
    if lens.maxAperture.length == 1 → return it
    f = clamp(focal, first.focal, last.focal); if f equals a breakpoint focal (1e-6) → that aperture
    segment a ≤ f ≤ b;  t = ln(f/a.focal) / ln(b.focal/a.focal)
    stops = log2(a.N²) + t·(log2(b.N²) − log2(a.N²));  exact = sqrt(2^stops)
    candidates = apertureScale(step: lens.apertureStep).values ∪ breakpoint apertures
    return the smallest candidate c with 2·log2(c / exact) ≥ −0.05
    ```
  - `double equivalentFocal(double focal, FilmFormat format)` = `focal × 43.27 / format.diagonalMm` (in fov.dart).
